# 🎯 Fiche Interview — Découverte des Besoins
## Coach Thérapeute de Couple · CRM & IA d'Aide à la Pratique

> **Objectif** : Cartographier précisément vos besoins métier pour concevoir un outil CRM augmenté par l'IA, parfaitement adapté à votre pratique de thérapie de couple — articulé autour de 3 axes stratégiques.

---

## 🧭 Feuille de Route Stratégique

Cette interview s'appuie sur **3 axes stratégiques** qui structurent la vision produit :

| Axe | Promesse de valeur |
|-----|-------------------|
| 🧠 **Mémoire clinique augmentée** | Transcrire les séances enregistrées, générer automatiquement des comptes rendus pour se rappeler rapidement le contexte entre deux séances et accompagner un nombre grandissant de patients. |
| 🔍 **Capacité d'analyse augmentée** | Disposer d'une IA conversationnelle contextuelle par dossier patient pour analyser les situations avec davantage de recul, approfondir certains aspects et obtenir des pistes de réflexion adaptées. |
| 📚 **Capitalisation méthodologique** | Transformer automatiquement le contenu de la pratique en fiches méthodologiques structurées à partir des séances, pour capitaliser sur l'expérience de terrain et développer des formations en ligne (scaling). |

## 4. 🧠 Axe 1 — Mémoire Clinique Augmentée

### 4A. Prise de notes & enregistrement actuels

| # | Question |

| 4.2 | Quel support utilisez-vous ? (papier, ordinateur, tablette, dictaphone…) |
| 4.3 | **Enregistrez-vous** vos séances (audio ou vidéo) ? Si oui, avec quel outil ? Si non, seriez-vous prête à le faire ? |
| 4.4 | Combien de temps passez-vous à rédiger/compléter vos notes après une séance ? |
| 4.5 | Quelle **structure** suivent vos notes ? (libre, SOAP, thématique, chronologique…) |
| 4.6 | Quels éléments notez-vous systématiquement ? *(cocher ce qui s'applique)* |
|     | ☐ Thème principal de la séance |
|     | ☐ Dynamique relationnelle observée |
|     | ☐ Émotions exprimées par chaque partenaire |
|     | ☐ Patterns / schémas récurrents identifiés |
|     | ☐ Exercices / tâches donnés pour l'inter-séance |
|     | ☐ Progrès constatés |
|     | ☐ Points de vigilance / risques |
|     | ☐ Autre : _________________________ |
| 4.7 | Avez-vous besoin de distinguer ce que dit/ressent **partenaire A** vs **partenaire B** dans les comptes rendus ? |

### 4B. Transcription & comptes rendus automatiques

| # | Question |
|---|----------|
| 4.8 | Si l'outil transcrivait automatiquement vos séances enregistrées, quel **format de compte rendu** serait idéal ? (résumé narratif, bullet points structurés, les deux…) |
| 4.9 | Quelle **longueur** idéale pour un compte rendu automatique ? (1 paragraphe, 1 page, détaillé…) |
| 4.10 | Quelles informations le compte rendu devrait-il **absolument** extraire ? (thèmes abordés, émotions clés, décisions prises, exercices prescrits…) |
| 4.11 | Aimeriez-vous que le compte rendu identifie automatiquement **qui parle** (Partenaire A / B / Thérapeute) ? |
| 4.12 | Consultez-vous vos notes précédentes **avant** chaque séance ? Combien de temps y consacrez-vous ? |
| 4.13 | Un **briefing de pré-séance** automatique (résumé des séances passées, points en suspens, exercices à vérifier) vous serait-il utile ? |
| 4.14 | À partir de combien de couples simultanés sentez-vous que votre **mémoire clinique** devient un facteur limitant ? |

## 5. 🔍 Axe 2 — Capacité d'Analyse Augmentée

### 5A. Méthodologie & cadre thérapeutique actuel

| # | Question |
|---|----------|
| 5.1 | Utilisez-vous un ou plusieurs **modèles thérapeutiques** structurés ? Lesquels ? |
| 5.2 | Suivez-vous un **protocole par phases** ? (ex. Phase 1 : évaluation, Phase 2 : dé-escalade, Phase 3 : restructuration…) |

| 5.4 | Suivez-vous des **indicateurs de progression** spécifiques ? Lesquels ? |
| 5.5 | Avez-vous une **bibliothèque d'exercices / interventions** que vous prescrivez ? Comment la gérez-vous ? |
| 5.6 | Participez-vous à des **supervisions** ? Avez-vous besoin de préparer des synthèses pour vos superviseurs ? |

### 5B. IA conversationnelle contextuelle

| # | Question |
|---|----------|
| 5.7 | Vous arrive-t-il de vous sentir **bloquée** face à un cas complexe ? Comment cherchez-vous de nouvelles pistes actuellement ? (lecture, supervision, intuition…) |
| 5.8 | Si vous pouviez « discuter » avec une IA qui connaît **tout l'historique** d'un couple (séances passées, patterns identifiés, exercices prescrits…), quelles **questions** lui poseriez-vous ? |
| 5.9 | Aimeriez-vous que l'IA vous propose des **hypothèses de travail** ou des **pistes d'intervention** basées sur les patterns détectés dans les séances ? |
| 5.10 | Seriez-vous intéressée par une **détection automatique de patterns récurrents** transversaux à plusieurs couples ? (ex. « 60% de vos couples présentent un pattern d'évitement-poursuite ») |
| 5.11 | L'IA devrait-elle pouvoir faire des liens avec des **références théoriques** (Gottman, EFT, systémique…) dans ses analyses ? |
| 5.12 | Quel **niveau de confiance** accorderiez-vous aux suggestions d'une IA ? Serait-ce un outil de réflexion ou un guide d'action ? |
| 5.13 | Quels **garde-fous éthiques** vous semblent indispensables pour une IA qui analyse des dossiers patients ? |

|     | ☐ Publier (articles, livre) |
